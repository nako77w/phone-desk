# Точка связи

«Точка связи» подключает Android к Windows без кабеля. С ноутбука можно запускать мобильные приложения, смотреть фото, передавать файлы и пользоваться текстовым буфером обмена.

## Bluetooth-компаньон для Android

См. [инструкцию предварительной сборки](BLUETOOTH.md).

## Скачать

Откройте [Releases](../../releases/latest) и скачайте **PhoneDesk-Setup-x64.exe**. Установщик добавляет «Точку связи» в меню «Пуск». Для переносимой версии скачайте **PhoneDesk-Portable-x64.zip**, распакуйте и запустите `Start.cmd`.

## Подключить телефон

1. Подключите Android 11+ и ПК к одной сети.
2. Откройте «Точку связи» и нажмите **Подключить телефон**.
3. На Android выберите **Параметры разработчика → Беспроводная отладка → Сопряжение с помощью QR-кода** и отсканируйте QR-код. Если автообнаружение не срабатывает, используйте ручное сопряжение из того же окна.

Трансляция работает в локальной сети. Поддерживаются Android и 64-разрядная Windows. Клавиатура и геймпад зависят от игры. Привязка WASD имитирует один экранный джойстик. Подробности есть в [инструкции](app/Инструкция.txt).

## Собрать

На Windows 64-bit с Inno Setup 6 выполните `./scripts/Build-Release.ps1`. Для ZIP без установщика добавьте `-PortableOnly`. Скрипт проверяет контрольные суммы зависимостей и запускает самопроверку приложения. Версионные теги `vX.Y.Z` публикуют установщик и ZIP в Releases через GitHub Actions.

Движок трансляции — [scrcpy](https://github.com/Genymobile/scrcpy). QR-коды генерирует [QRCoder](https://github.com/codebude/QRCoder). Лицензии этих компонентов входят в сборку.
